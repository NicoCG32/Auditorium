Evaluación de metadatos y reproductores

Prototipo aislado MEDIA-01. No conecta con tu biblioteca. Sólo los botones de consulta, imagen y reproductor contactan al proveedor. Un título o miniatura de vídeo, pista o lista no identifica por sí solo un álbum.

Borrador manual de revisión

El nombre del canal o autor del enlace no se asigna como banda. Este borrador no se persiste.

Acciones independientes

Al solicitar una consulta o reproductor, el proveedor recibe el enlace elegido, tu dirección IP y datos técnicos; su marco puede usar cookies. Revisa las condiciones de YouTube, la privacidad de Google y las condiciones del widget Spotify antes de continuar. Tu borrador manual no se envía.
